# Cosmos Explorer

Página web sobre el espacio y los planetas del sistema solar.

## Descripción

Proyecto hecho solo con **HTML** y **CSS**. La web tiene:

- Un header y un footer responsive.
- Una sección principal (hero).
- Una sección con los planetas del sistema solar.
- Una galería con 10 imágenes.
- Una sección sobre la exploración espacial.

El diseño es responsive con **flexbox** y **media queries** para tres tamaños: ordenador, tablet y móvil.
